## Description

This dataset is used for rebar segmentation model training. It contains images
and annotations from two open source Roboflow Universe datasets:

- Rebar: https://universe.roboflow.com/sitevision-tnmlg/rebar-3dl2l
- Rebar Seg: https://universe.roboflow.com/roomsegment/rebar-seg

The merged dataset contains 1,031 annotated images split into training,
validation, and test sets:

- Train set: 784 images (76%)
- Validation set: 165 images (16%)
- Test set: 82 images (8%)

No preprocessing was applied to the source images. No augmentation was applied
when creating this dataset version.
